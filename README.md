# NEXUS VPN Landing

> Modern VPN service landing page built with Tailwind CSS + GSAP scroll animations.

## Stack

- **Tailwind CSS v4** — utility-first styling via CDN
- **GSAP + ScrollTrigger** — smooth scroll-driven animations
- **Vanilla JS** — zero dependencies, fast load
- **Responsive** — mobile-first, tested on iOS/Android

## Features

- Animated hero with Vanta.js NET background
- Pricing cards with toggle (monthly/yearly)
- Feature grid with scroll-triggered reveals
- FAQ accordion
- Telegram bot integration for purchases

## Preview

Dark theme, performance-focused — Lighthouse 95+ on mobile.
